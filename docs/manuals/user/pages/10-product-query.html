商品清單紀錄查詢

本頁重點

  • 查內部「商品列表」資料夾裡的檔。
  • 可依 自定義編碼 或 c（條碼）一次貼多筆篩選。
  • 可下載目前畫面（全檔或篩選結果）。

何時使用

核對自家 SKU、條碼，或匯出某一版商品列表。

操作步驟

  1. 選雲端商品清單檔。
  2. 選查詢欄位：自定義編碼 或 c。
  3. 貼多筆代碼（換行、逗號或空格皆可）。
  4. 看篩選結果；空白貼上區則顯示全表。
  5. 下載。

預期檔案

「商品列表」資料夾內的 商品列表.xlsx 及同資料夾其他檔。

常見問題

  • 目前雲端無歷史單據：資料夾是空的或沒有權限。
  • 篩選 0 筆：代碼與欄位不一致，或條碼被 Excel 變成科學記號。
