# 各表最新修改時間

路徑：雲端資料狀態 → 各表最新修改時間

## 本頁重點

- 列出各 Drive 來源「最新一檔」與台北時間。
- 「已接入流程」會被程式讀寫；其餘蝦皮資料夾只監看。
- 按「重新整理狀態」可清快取再掃一次。

## 何時使用

每日開工、懷疑檔案沒上傳、或定時同步前後，用來確認來源是否到齊。

## 操作步驟

1. 左側選 **雲端資料狀態** → **各表最新修改時間**。
2. 看表格：資料夾、檔名、修改時間、用途。
3. 需要最新狀態時，按 **重新整理狀態**。

## 表格怎麼看

| 用途 | 意思 |
|------|------|
| 已接入流程 | 入庫、三表整合、蝦皮校正、UPC 會用到 |
| 僅監看 | 例如蝦皮媒體、標題描述、配送、未上架；不會寫入主表 |

已接入的來源包括：麗嬰總表、商品列表、蝦皮賣場列表、價格統整表、Sitegiant UPC、Sitegiant BasicInfo、蝦皮價格及庫存（mass_update）、預購追蹤.xlsx、Sitegiant_Preorder_Orders（All Orders）。

「僅監看」另含蝦皮媒體／標題描述／配送／未上架，以及 Import Restock 官方殼。

頁面下方會顯示「已接入 N 個來源，僅監看 M 個」。

## 預期檔名（節錄）

- `麗嬰採購產品總表.xlsm`
- `商品列表.xlsx`
- `蝦皮賣場商品列表.xlsm`
- `商品蝦皮麗嬰價格統整表.xlsx`
- `batch_edit_item_upc_assignment_all_DD-MM-YYYY-*.xlsx`（或 zip）
- `batch_edit_basic_info_all_DD-MM-YYYY-*.xlsx`（或 zip）
- `mass_update_sales_info_3062950_YYYYMMDD*.xlsx`
- `預購追蹤.xlsx`
- `Orders_DD-MM-YYYY-*.xlsx`

## 常見問題

- **掃描失敗（憑證缺失／無效或資料夾無權限）**：找工程師；不要把金鑰貼到聊天或畫面。
- **某列沒有檔名**：該資料夾是空的，或 service account 沒有檢視權限。
- **時間看起來舊**：來源還沒上傳，或按重新整理。

「每日郵件摘要」區塊目前尚未啟用寄信；定時同步仍會把同一份狀態寫進 GitHub Actions 工作摘要。
