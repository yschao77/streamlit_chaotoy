# 採購單待處理

路徑：Sitegiant 電商整合管理 → 採購單待處理

## 本頁重點

- 顯示入庫轉換時對不到統整表的異常商品。
- 本頁以查看、下載為主；清單會在入庫轉換時自動新增或清掉。
- 狀況通常是「須建立自定義編碼」或「須建立賣場商品」。

## 何時使用

入庫轉換出現警告之後，或要清積壓的缺料／缺 SKU。

## 操作步驟

1. 打開本頁，等待雲端清單載入。
2. 沒有資料即表示目前沒有待處理。
3. 有資料時看：採購單檔名、國際條碼、狀況、狀態、建立時間。
4. 需要時下載 Excel。
5. 按 **重新載入最新雲端資料** 可清快取再讀。

處理方式：

- **須建立自定義編碼**：在內部商品列表補 SKU，再跑三表整合，然後重做入庫或等下次轉換自動清掉。
- **須建立賣場商品**：補 Sitegiant／統整表的 `sitegiant庫存SKU` 後再轉換。
- 若在待處理檔把「狀態」改成不是「待處理」，下次入庫轉換也會把它從清單移除。

## 預期檔案

雲端「尚未建立商品清單」試算表（由入庫轉換維護）。

## 常見問題

- **讀取雲端清單失敗**：檔案尚未建立，或 service account 沒有權限。第一次成功跑入庫轉換後通常會出現。
- **清單有舊資料**：到入庫頁用同一批條碼再轉一次（已對得上會自動清），或請有權限者在雲端改狀態。
