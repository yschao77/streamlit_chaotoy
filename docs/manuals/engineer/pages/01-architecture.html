架構與資料流

本頁重點

  • Streamlit 單頁應用；側邊欄 selectbox 選模組、radio 選子頁。
  • Drive／Excel 的唯一實作在 utils.py；views/ 只 render。
  • 三表整合與蝦皮／UPC 同步，畫面與 CLI 走同一組函式。

執行時資料流

  1. app.py 設定 page_config、套用 openpyxl patch、用關鍵字查出主檔 ID。
  2. 組成 gdrive_cfg（或個別 Drive ID）傳給 views/*.render。
  3. 子頁開頭固定：st.title + 麵包屑。
  4. 讀檔／寫檔都走 utils 的 Drive 函式。
使用者 → app.py 路由 → views/* → utils.py → Google Drive Excel/xlsm

三個模組

側邊欄模組檔案子頁

新子頁：先在 app.py 的 radio 加字串，再在對應 views 加 if sub_page == "..."。字串必須完全一致。

對鍵與計算

  • 商品列表 ⟕ 蝦皮（自定義編碼 = iSKU）
  • 再 ⟕ 麗嬰（c = 條碼）
  • sitegiant庫存SKU：c 對 batch_edit UPC 的庫存貨品名稱

入庫單名稱只抓 sitegiant庫存SKU。財務：八折 × 0.8、未稅 ÷ 1.05。
