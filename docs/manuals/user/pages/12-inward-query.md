# 查詢入庫紀錄

路徑：Sitegiant 電商整合管理 → 查詢入庫紀錄

## 本頁重點

- 用國際條碼或庫存 SKU，查出商品出現在哪幾張歷史入庫單。
- 結果含銷貨日期、進貨數量、資料夾（`YYYY/YYMM`）與檔名。
- 查詢先讀根目錄 `入庫明細索引.xlsx`；入庫單有增刪改才重掃並覆寫索引。

## 何時使用

要知道某商品是哪天、哪張單、進了多少，而不想一張張打開入庫 Excel。

## 操作步驟

1. 打開本頁，等待索引載入（第一次或入庫單有變動時較久）。入庫單有新增後可按 **重新載入索引**。
2. 選查詢欄位：`國際條碼` 或 `庫存SKU`。
3. 貼多筆代碼（換行、逗號或空格皆可）。
4. 看明細與進貨數量合計；同一商品多張單會全部列出（日期新→舊）。
5. 需要時下載結果。

空白貼上區則顯示索引全部列。

## 預期檔案

- 讀：歷史入庫根目錄與 `YYYY/YYMM` 子資料夾內的入庫單 `.xlsx`
- 讀寫：根目錄 `入庫明細索引.xlsx`（雲端既有檔，系統依檔 ID 覆寫，不新建）

入庫單請放到例如 `2026/2608/`（西元年／年月），不要只放在本機。轉換頁下載的檔若還沒上傳到對應月份，這裡查不到。

## 常見問題

- **索引寫回失敗**：找工程師確認 service account 對歷史入庫資料夾有編輯權，以及 `入庫明細索引.xlsx` 的檔 ID 是否仍有效。
- **篩選 0 筆**：代碼與欄位不一致，或該商品不在已上傳的入庫單裡。
- **日期空白**：檔名不是 `sitegiant採購入庫單_yymmdd_廠商_單號.xlsx`，且表內也沒有「銷貨日期」。
- **第一次很慢**：正在把各張入庫單合併成索引；之後來源沒變就只讀索引。
- **憑證缺失／無效**：找工程師，不要貼金鑰。
