# 預購追蹤

路徑：**🗓️ 預購追蹤**（第四主模組，與 Sitegiant／蝦皮麗嬰同層）

側邊欄先選模組 **🗓️ 預購追蹤**，再選子頁：

| 子頁 | 職責 |
|------|------|
| **總覽** | 生命週期看板、待辦數字；可一鍵跳到其他工作區 |
| **建檔／補資料** | 廠商單帶入＋補 SKU／自購／上限／存檔 |
| **對訂單** | All Orders 看板；狀態欄**唯讀** |
| **結單** | 勾選鎖定、下載兩檔、結單紀錄同步 |
| **到貨催款** | **標到貨**（唯一可改狀態處）＋催款／可打單 |

各子頁頂部共用「重新載入預購追蹤」與「計算規則／採購單空殼」摺疊區。

## 本頁重點

- **建檔／補資料 → 從廠商單帶入：** 勾選列寫入活動表（沒條碼只要勾選也會寫入）。對到既有列只更新廠商檔名／貨號／品名／條碼，不覆蓋 SKU、自購、上限、私密連結、結單日。**已實際關閉的列不覆寫。**
- **建檔／補資料 → 補賣場資料並存檔：** 手填 SKU、自購、上限、月份、**賣場後台連結**；**結單日用欄位內日期時間挑選器**（有 SKU 必填，寫回 `YYYY-MM-DD HH:mm`；**僅此子頁可編**，其他子頁只讀）後覆寫雲端 `預購追蹤.xlsx`。覆寫成功後會同步 Google 日曆結單事件（見下方「結單日 × Google 日曆」）。已填「實際關閉」的列不能改自購／上限／SKU／月份／結單日；品名、私密連結、賣場後台連結、條碼、貨號仍可改。清空實際關閉＝重開。
- **對訂單：** 只計 **商品名稱含「預購」** 的列，再依活動 SKU 計件，拆成 **已付款／未付款**，並對上限。同時重寫 **預購訂單** 表、補上尚未列過的 SKU（預設「預購」）。彙總表的「狀態」欄**唯讀**；要標到貨請到「到貨催款」。雲端讀最新 `Orders_DD-MM-YYYY-*.zip` 並解成 xlsx。
- **結單：** 勾選要結單的列；自購可在這張表改（按預覽才寫入活動表，不會自動覆寫雲端）。再預覽鎖定數量後確認。`訂量 = 自購 + min(客戶量, 上限)`。上限空＝不封頂；自購空＝0。未填 SKU、未勾選、已實際關閉的列不鎖定。下載已填訂量的廠商檔與 **SiteGiant 採購單**（後台：Purchase Order → Import Restock Products）；已填訂量檔同時會同步到 Drive「預購結單紀錄」。鎖定後在同一區覆寫雲端。
- **到貨催款：** 「標到貨」**只列狀態＝預購且已接單（客戶量）＞0** 的 SKU（已到貨、零接單不出現）。改成 **到貨** 後：未付款可催款（表上有首次通知日／已過天數，已通知預設不勾）；已付款且訂單狀態 **待處理** 產可打單名單。通知紀錄畫面只列仍未付款並顯示已過天數。打單、取消、勾已收到付款仍在 SiteGiant。
- 寫回是覆寫既有檔，系統不會在 Drive 新建檔。（結單時同步的「結單紀錄」除外，該專用資料夾／彙整檔路徑允許更新）
- SiteGiant 採購單官方空殼只給你本機下載（各子頁頂部摺疊區或結單區），填好的檔也不會寫回那個空殼。
- 本機上傳的 Orders 只作看板預覽，不會上傳到 Drive。

狀態以 SiteGiant 官方為準：[訂單、付款與處理狀態的運作方式](https://support.sitegiant.com/zh/knowledge-base/how-the-order-payment-and-fulfillment-status-works-zh/#2-e8a882e596aee78b80e6858b)。工作表 **預購訂單** 不是官方訂單狀態「待處理」。

與先前工程分期對照：第1階＝建檔活動表；第2階＝對訂單看板；第3階＝建檔匯入＋結單；第4階＝到貨催款。

三張單分開看：

| 檔 | 用途 |
|----|------|
| 廠商訂購單 | 寄給廠商下單；結單只回填 `訂量` |
| SiteGiant 採購單 | 結單後上傳後台建 PO（填 iSKU＋鎖定數量） |
| 採購入庫單 | 貨到才用；現有 Sitegiant「採購入庫單格式轉換」 |

## 何時使用

要從廠商訂購單帶入貨號／品名／條碼、登錄預購活動、查看已接單與付款兩欄、把 SKU 標到貨後催款／看未付款天數、結單後回填廠商訂量與下載 SiteGiant 採購單時。

## 操作步驟

左側選 **🗓️ 預購追蹤** → 再選子頁。需要雲端最新內容時按 **重新載入預購追蹤**。計算規則與空殼下載在各子頁頂部摺疊區。總覽可按按鈕跳到對應工作區。

### 建檔／補資料 → 從廠商單帶入

1. 上傳該次廠商原始訂購單（**xlsx 或 xls**）。表頭不一定在第 1 列；系統會找訂量（或數量），以及條碼／貨號。品名、條碼、貨號欄名與麗嬰合併同一套同義（例如 `名稱`／`中文品名`／`品名規格`／`Description`，`條碼型號`／`JAN CODE`，`料品編號`／`Item No`）。
2. 預覽後勾選要跟的款。**沒條碼的列只要勾選也會匯入。**
3. 按 **把勾選列寫入活動表**。未勾選的列不寫入。
4. 同一檔再匯入一次時，已填的 SKU／自購不會被蓋掉。**已實際關閉的列整列不覆寫**（貨號／品名／條碼也不改）。

不要把整份廠商目錄無條件全選（麗嬰型可能上百列）。這一頁不從商品清單帶貨號（未來待做）。

### 建檔／補資料 → 補賣場資料並存檔

1. 活動表左邊是月份、結單日、SKU、自購、上限；貨號／條碼在右邊。
2. SKU 填蝦皮 `自定義編碼`（與 SiteGiant 庫存 SKU 同一顆）。四款就填四個不同 SKU。不要把廠商貨號填進 SKU。
3. 空 SKU、同一 SKU 多列、SKU＝貨號，畫面會警告。
4. **結單日：** 點欄位用日期時間挑選器（寫回雲端為 `YYYY-MM-DD HH:mm`）。有填 SKU 的列必填；不要手打自由格式。結單日**只在本子頁可編**。
5. **賣場後台連結：** 可貼 SiteGiant 商品後台 URL；會寫進日曆事件描述（進行中／已關閉皆可改）。
6. **已填實際關閉：** 自購、上限、SKU、月份、結單日不能改（畫面改了會還原）。品名、私密連結、賣場後台連結、條碼、貨號仍可改。要再改自購或重算訂量，先清空實際關閉（重開）。
7. 按 **覆寫雲端預購追蹤**（會一併同步 Google 日曆）。也可先下載本機副本核對。

活動表改 SKU 或上限後，到「對訂單」看板會依目前 session 重算，不必先存檔才能預覽。

### 對訂單

這一段拆成兩個分頁：**📋 看板與明細**（日常操作）跟 **🧾 原始訂單明細**（除錯／稽核用）。

1. 看「雲端最新 All Orders」檔名與時間（資料夾 `Sitegiant_Preorder_Orders`，檔名 `Orders_DD-MM-YYYY-*.zip`，系統會解成 xlsx；例如 `Orders_16-09-2026-1789531035`）。
2. 若要核對本機匯出，打開 **本機上傳 All Orders 預覽**（預設收合，可傳 zip 或 xlsx）；畫面會標「未寫入 Drive」。
3. **📋 看板與明細**分頁：一張彙總表列出每個 SKU 的品名、階段（收單中／已結單待到貨／催款中／完成）、已接單／上限、已付款／未付款件數、達上限、狀態（**唯讀**；要改「到貨」請到「到貨催款」）。上方有搜尋框可依 SKU／品名篩選。「在活動表」＝否表示這個 SKU 有訂單或曾經到貨、但活動表還沒建對應列，數字欄留空。
4. 要看某個 SKU 的逐筆訂單，在彙總表下方的下拉選單選取（可多選）；已付款／未付款會合併成一張表，未付款排前面。不選就不會顯示明細，避免 SKU 一多整頁被撐長。
5. **狀態**會自動補上預購列裡的 SKU，預設「預購」。在「到貨催款」標「到貨」後才進催款／可打單。
6. **🧾 原始訂單明細**分頁：最新 All Orders 快照，含所有預購訂單列（不分活動/SKU 是否對得上），含首次通知日與已過天數；一樣有搜尋框（SKU／訂單編號／商品名稱）。這裡的數字是稽核用，跟上面彙總表口徑可能不完全一樣（例如含未在活動表的 SKU）。
7. 已接單達到或超過上限會出現提醒。

### 結單

1. 確認活動列已填 SKU。同一 SKU 不要出現在多列（畫面會警告）。
2. 在勾選表取消不要結的列（預設全勾；未填 SKU／已實際關閉的列不會出現）。需要補自購可直接在這張表改；上限仍請回「建檔／補資料」改。
3. 按 **預覽鎖定數量**。這時才把表上的自購寫入活動表（尚未覆寫雲端）。鎖定數量 = 自購 + min(已接單, 上限)。核對表格後再按 **確認鎖定**。同場再確認會取代尚未存檔的廠商單歷史。已實際關閉、未勾選的列會列出「不鎖定」，不會進這次廠商單歷史。若改了勾選或自購請再按預覽。勾選表上的鎖定數量在按預覽前可能還是舊的。
4. 下載已填 `訂量` 的廠商檔（只改訂量，標題與圖片會留著；若原檔是 **xls**，會轉成值工作簿再回填，下載／同步檔仍是 xlsx）。先對條碼，沒條碼再對貨號；對不上會列出來、不填假數量。同時會同步更新／新建到 Drive「預購結單紀錄」，檔名尾綴 `_結單紀錄`；同步失敗不影響本機下載，改勾選重新預覽／確認鎖定會重試。
5. 下載 SiteGiant 採購單（iSKU + 鎖定數量）。拿到 SiteGiant Purchase Order → Import Restock Products 上傳。雲端空殼不會被改。
6. 在**同一區**按 **覆寫雲端預購追蹤**，把「廠商單歷史」、預購訂單、SKU 狀態、通知紀錄與實際關閉寫回 Drive。不必回到建檔子頁存檔。

若尚無 All Orders，請先到「對訂單」載入。

### 到貨催款

1. **標到貨**（本頁開頭表格）：**只列出狀態仍為「預購」且已接單（客戶量）＞0 的 SKU**（已到貨、零接單／尚未對到訂單不出現）。把狀態改成 **到貨**（唯一可改處；「對訂單」看板是唯讀）。改完按「覆寫雲端預購追蹤」才寫回。還沒標到貨的不進催款／可打單。尚未載入 All Orders 時表會是空的，請先到「對訂單」載入。
2. **逐筆選要通知的未付款訂單**（摺疊區）：到貨 SKU、付款狀態未付款、非已取消／已退款。表上有 **首次通知日**／**已過天數**；已有首次通知日的列**預設不勾**，避免重複通知（整批蓋章也不會改既有日期）。可全選刻意全勾。
3. **可打單名單**（摺疊區，預設收合）：到貨 SKU、已付款、且訂單狀態＝**待處理**（官方才會出現在訂單處理頁）。已處理／已發貨／已完成不列入。
4. 按 **本次催款已通知且覆寫雲端預購追蹤**：幫還沒日期的未付款列點上今天；已有日期不改。日期寫在工作表 **通知紀錄** 與 **預購訂單**，並立刻覆寫雲端整份預購追蹤。
5. **通知紀錄**（畫面）：只列**仍未付款**的通知列，並顯示 **已過天數**；已付款／已退款／已取消不顯示（工作表列仍保留）。不設取消門檻；要取消請到 SiteGiant。
6. 打單、勾已收到付款、Notify Customer 仍在 SiteGiant。

若尚無 All Orders，請先到「對訂單」載入。All Orders 若有顧客／收件／金額欄會一併帶上；沒有就不猜。

## 付款與訂單狀態怎麼用

| 用途 | 規則 |
|----|------|
| 已接單 | 商品名稱含「預購」、訂單狀態不是已取消；商品數量加總 |
| 已付款／未付款 | 只看 `付款狀態`。不看付款方式、不拆貨到付款 |
| 催款 | 到貨 SKU、未付款、非已取消、非已退款 |
| 可打單 | 到貨 SKU、已付款、訂單狀態＝待處理 |
| 已過天數 | 有首次通知日，且仍是未付款、未取消、未退款 |

官方常見路徑：銀行轉帳 → **新訂單 + 未付款**（催款）→ 你對帳後標記待處理並勾已收到付款 → **待處理 + 已付款**（可打單）。

對鍵用 All Orders **庫存SKU**；該格空白才改用 **商品SKU**。不過濾 `商城`。

## 活動表欄位

畫面由左到右：月份、結單日、SKU、自購、上限、品名、條碼、貨號、廠商檔名、私密連結、賣場後台連結、預計關閉、實際關閉、日曆事件ID。寫回雲端的欄位集合不變。有「實際關閉」的列鎖自購／上限／SKU／月份／結單日；清空該格＝重開。賣場後台連結進行中／已關閉皆可改。日曆事件ID 由系統維護，請勿手改。

SKU 填蝦皮 `自定義編碼`（與 SiteGiant 庫存 SKU 同一顆）。條碼填 GTIN／商品列表 `c`。貨號、廠商檔名通常由訂購單匯入。

`預購追蹤.xlsx` 另含工作表：預購訂單、SKU狀態、通知紀錄。

## 結單日 × Google 日曆

覆寫雲端 `預購追蹤.xlsx` **成功後**，系統會依活動表同步指定 Google 日曆（不回滾已成功的 Drive 存檔；失敗只顯示警告）。

**同一「廠商檔名」只建一筆日曆事件**（該檔下多個 SKU 共用）；無廠商檔名時才依 SKU 各建一筆。組內多個結單日時用**最早**的；組內 SKU **全部**填了實際關閉才標已結。

| 項 | 規則 |
|----|------|
| 標題 | `[預購結單] {月份} {廠商檔名}`（缺廠商檔名則用 SKU） |
| 已實際關閉 | 組內全關閉 → 標題改 `[已結][預購結單] …`，並關閉提醒；事件保留 |
| 時間 | 開始＝組內最早結單日（台北）；結束＝該日＋2 天（同鐘點）。可自行在日曆提早結束 |
| 提醒 | **無法由程式替共用日曆成員強制 popup**（API 的 reminders 只對寫入的 service account 私有）。未關閉事件用「套用日曆預設通知」；請在該結單日曆設定「活動通知＝開始前 2 小時」（見下方）。已結事件關閉 SA 側覆寫提醒。 |
| 描述 | 賣場後台連結（有則列）、組內全部 SKU、固定一句「請至 Streamlit 預購追蹤結單」 |
| 改期 | 同一日曆事件更新；同組各列寫入相同「日曆事件ID」 |
| 清空結單日（組內皆不再合格） | 刪除事件並清空該組「日曆事件ID」 |
| 舊版每 SKU 一筆 | 下次覆寫時會合併：保留一筆、刪多餘重複事件 |

### 第一次啟用（管理員）

1. 在 GCP 專案啟用 **Google Calendar API**（與 Drive 同一組 service account）。
2. 開啟該結單用 Google 日曆 → 設定 → 與特定使用者共用 → 加入 **service account 的 client_email**，權限選**編輯活動**。
3. **每位要收提醒的人**（含自己）：Google 日曆 → 左側該結單日曆右側 ⋮ → 設定與共用 → **活動通知** → 新增「通知」或「電子郵件」，時間選 **2 小時前**（可再加一組）。未設這步，覆寫雲端建出的事件不會在你的帳號跳出提醒。
4. 之後一般操作只要在「建檔／補資料」填結單日並按覆寫雲端即可（結單日須在未來，已過的時間不會補推播）。

## 預期檔案

- 讀寫：`預購追蹤.xlsx`（既有 file id）
- 只讀：SiteGiant 採購單官方殼（填好的檔只本機下載，檔名如 `sitegiant採購單_預購_YYYYMMDD.xlsx`）
- 「對訂單」讀取：`Sitegiant_Preorder_Orders` 的最新 `Orders_DD-MM-YYYY-*.zip`（解成 xlsx；也可本機上傳 zip／xlsx 預覽，不上傳）
- 「建檔／補資料」／「結單」上傳：該次廠商原始訂購單（xlsx 或 xls，例如 `2026-License(SJ0910).xlsx`）
- 「結單」同步寫入：Drive「預購結單紀錄」資料夾裡的 `{原廠商檔名}_結單紀錄.xlsx`（或彙整檔 `預購結單紀錄.xlsx`）

## 常見問題

- **找不到預購追蹤：** 入口已升成第四主模組，不在 Sitegiant 子頁列表裡。
- **無法載入預購追蹤**：service account 沒有該檔編輯權，或檔不是 `.xlsx`。
- **覆寫成功但出現日曆警告**：雲端追蹤檔已存；請確認 GCP 已啟用 Calendar API，且結單日曆已把 service account（`client_email`）加為**編輯者**。修權限後再覆寫一次即可補同步。
- **無法讀取 SiteGiant 採購單空殼**：service account 沒有該檔檢視權。看頂部摺疊「計算規則與 SiteGiant 採購單空殼」。
- **無法載入 All Orders**：資料夾是空的、沒有 `Orders_DD-MM-YYYY-*.zip`（或 xlsx），zip 內沒有試算表，或 service account 沒有該資料夾檢視權。可改本機上傳預覽。
- **看板件數是 0**：商品名稱沒有「預購」（現貨匯出）；或活動 SKU 與預購列的庫存SKU 不一致；或該 SKU 都是已取消。
- **「逐筆選要通知的未付款訂單」沒有出現**：SKU 還是「預購」、還沒在「到貨催款」標到貨；或沒有未付款列。
- **標到貨表看不到已到貨的 SKU**：設計如此；該表只列狀態仍為「預購」且已接單＞0 的列。
- **標到貨表看不到已接單＝0 的 SKU**：設計如此；沒有客戶預購訂單的 SKU 不必標到貨催款。
- **標到貨表是空的、但活動表有預購列**：可能還沒到「對訂單」載入 All Orders，或這些 SKU 客戶量都是 0。
- **已通知列還在通知紀錄**：若 All Orders 仍是未付款就會顯示（含已過天數）；已付款／已退款／已取消才從畫面消失（工作表列仍保留）。
- **「對訂單」改不了狀態**：這是設計；要標到貨請到「到貨催款」。
- **可打單是空的**：還沒改成官方「待處理」＋已付款。
- **廠商檔找不到表頭**：需要有訂量（或數量），以及條碼或貨號欄。品名／條碼／貨號可用麗嬰合併那套同義欄名（`名稱`、`中文品名`、`JAN CODE`、`Item No` 等）。支援 `.xlsx`／`.xls`；若仍打不開再另存一次試試。
- **已關閉列改不了自購／SKU**：這是保護；清空「實際關閉」即重開。廠商單再匯入也不會覆寫已關閉列。
- **訂量沒填上**：活動列沒 SKU（未鎖定），或條碼／貨號對不到。看畫面對不上清單。
- **結單紀錄同步雲端失敗**：跟主檔存檔是分開的。個人雲端請先在「預購結單紀錄」資料夾**手動建立空白 `預購結單紀錄.xlsx`**（分享給 service account 編輯），再預覽／確認鎖定；系統會把訂量併入此彙整檔。或把資料夾改放到共用雲端硬碟即可逐檔新建。
- **廠商檔很多列顯示未鎖定**：正常；開單時未開放預購／未勾選鎖定的品項會收進摺疊區，可忽略。真正要處理的是「已鎖定卻對不到廠商檔」的警告。
- **SiteGiant 採購單匯入失敗**：iSKU 必須已在 SiteGiant 庫存。
- **匯入後 SKU 有值**：不是從廠商單帶入。新列 SKU 應空白；若條碼／貨號已在活動表，會保留該列原本的 SKU。貨號（如 `09398`）應在「貨號」欄。請重新整理頁面後再看欄位有沒有對齊。
- **廠商單歷史沒有自購**：可在「建檔／補資料」活動表或「結單」勾選表填自購，再按預覽／確認鎖定；鎖定預覽列應看得到自購。然後在「結單」覆寫雲端。若只在結單表改自購、還沒按預覽，「建檔」存檔仍是舊值。
- **存檔後畫面仍是舊的**：再按重新載入；不要同時開兩個分頁互相覆蓋。
