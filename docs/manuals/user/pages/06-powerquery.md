# PowerQuery 執行三表整合

路徑：商品蝦皮麗嬰統整管理 → PowerQuery 執行三表整合

## 本頁重點

- 把內部商品列表、蝦皮主表、麗嬰總表交叉成價格統整表。
- 用最新 Sitegiant `batch_edit_basic_info_all_*.xlsx` 填 `sitegiant庫存SKU`。
- 預覽確認後，再按回寫，才會覆寫雲端統整表。

## 何時使用

蝦皮或麗嬰有更新、要做入庫之前、或要重算八折／未稅／稅款。

## 操作步驟

1. 看三個指標是否「已對接」：商品列表、蝦皮主表、麗嬰總表，以及各自最後修改時間。
2. 確認雲端已有空白／既有的 `商品蝦皮麗嬰價格統整表`。
3. 確認有最新 `batch_edit_basic_info_all_DD-MM-YYYY-*.xlsx`（沒有則 `sitegiant庫存SKU` 會空白）。
4. 按 **啟動三表整合與財務指標計算**。
5. 預覽列數與 `sitegiant庫存SKU` 來源檔名。
6. 可先下載本機 Excel；確認無誤後按 **將整合結果回寫並更新至雲端**。

## 系統會算什麼

對鍵：`自定義編碼` = 蝦皮 `iSKU`；內部 `c` = 麗嬰 `條碼`；`c` = batch_edit 國際條碼（UPC）。

| 欄位 | 說明 |
|------|------|
| 麗嬰零售八折 | 麗嬰零售價 × 0.8 |
| 麗嬰八折比蝦皮貴 | 八折高於蝦皮售價則標記 |
| 麗嬰未稅價 | 批發含稅價 ÷ 1.05 |
| 麗嬰稅款 | 含稅 − 未稅 |
| sitegiant庫存SKU | batch_edit 的庫存貨品名稱 |

## 預期檔案

- 讀：`商品列表`、`蝦皮賣場商品列表.xlsm`、`麗嬰採購產品總表.xlsm`、Sitegiant BasicInfo
- 寫：覆寫既有 `商品蝦皮麗嬰價格統整表.xlsx`（雲端必須先有這份主檔）

## 常見問題

- **缺少核心資料主檔案 ID**：三個主檔有缺，先看「各表最新修改時間」。
- **雲端不存在統整表空白主表**：不能新建；請先在 Drive 放好主檔再跑。
- **sitegiant庫存SKU 全空**：BasicInfo 檔名不對或資料夾沒檔。
