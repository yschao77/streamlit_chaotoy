定時同步

本頁重點

  • Workflow：.github/workflows/sync-shopee.yml
  • 排程：cron 0 2 * * *（UTC 02:00，約台北 10:00），也可手動觸發
  • 憑證用 repo Secret 注入環境變數，不要把 JSON 寫死在 YAML

步驟順序

前三步 continue-on-error: true；最後狀態報告 if: always()。

  1. scripts/sync_shopee_from_gdrive.py — 最新 mass_update → iSKU → 覆寫蝦皮主表。md5 重複則略過。
  2. scripts/sync_price_summary.py — 三表 + BasicInfo → 覆寫統整表。雲端必須已有主檔。
  3. scripts/sync_sitegiant_upc.py — 填空白 UPC → batch_edit_upc_added_only.xlsx。
  4. scripts/report_gdrive_status.py — 最新檔與台北時間，寫入 Actions Summary。

本機可跑同一支 script，需先設 GOOGLE_SERVICE_ACCOUNT_JSON。

可選郵件

同時有 STATUS_MAIL_TO 與 SMTP_HOST 才寄信。沒有這些 Secret 時不會寄信。

失敗時

個別 sync 失敗不會擋住狀態報告。看 Actions log 的退出原因，不要把憑證貼進 issue。
