# Sitegiant 歷史入庫單紀錄

路徑：Sitegiant 電商整合管理 → Sitegiant 歷史入庫單紀錄

## 本頁重點

- 用統整表 `c` → `sitegiant庫存SKU` 更新入庫單「庫存貨品名稱」。
- 雲端已有同檔名才覆寫；沒有同名檔只給本機下載，不會新建。
- 可調閱單張歷史單並看成本、稅款加總。

## 何時使用

舊入庫單名稱不對、或要把本機入庫 Excel 對回最新統整表。

## 操作步驟

### 批次匯入歷史入庫單

1. 上傳一或多個 `.xlsx` / `.xls`。
2. 按 **依統整表更新庫存貨品名稱並匯入**。
3. 看每檔結果：已覆寫、僅下載、找不到對應、SKU 空白。
4. 需要時下載更正後檔案。

### 批次修正雲端既有單據

1. 多選雲端已有的歷史入庫單（預設全選）。
2. 按 **依統整表更新所選單據的庫存貨品名稱**。
3. 確認覆寫筆數與找不到的條碼。

### 調閱與加總

1. 選一張入庫對帳單。
2. 看明細；下方顯示「成本 × 數量」「稅款 × 數量」總額。
3. 可下載該檔。

## 預期檔案

- 讀：`商品蝦皮麗嬰價格統整表.xlsx`（沒有主檔時用後備統整表）
- 讀寫：歷史入庫資料夾既有 `.xlsx`

## 常見問題

- **雲端沒有同名檔，未寫入**：系統不新建 Drive 檔；請先在該資料夾手動建立同名檔，或只下載本機檔再自行上傳。
- **找不到統整表對應**：條碼不在統整表 `c`。
- **sitegiant庫存SKU 空白**：先跑三表整合，並確認 Sitegiant BasicInfo 有 `batch_edit_basic_info_all_DD-MM-YYYY-*.xlsx`。
- **憑證缺失／無效**：找工程師，不要貼金鑰。
