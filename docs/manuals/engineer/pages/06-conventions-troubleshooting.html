開發慣例與故障排除

本頁重點

  • 共用邏輯只改 utils.py；頁面不要重寫 clean_barcode。
  • Drive service 用 @st.cache_resource；檔案／主表 @st.cache_data(ttl=600)。寫入後要清 cache。
  • 憑證錯誤維持「憑證缺失／無效」，不要把例外全文（可能含金鑰）丟到畫面。

慣例

from utils import clean_barcode
df["條碼"] = df["條碼"].map(clean_barcode)
  • 使用者看得到的失敗用 st.error；不要空的 except: pass
  • Drive 連線失敗可 st.stop()
  • views/ 既有 sys.path 補丁可保留，新檔不要再複製一份

快取

寫雲端成功後常見要清：load_master_data、load_shopee_data、get_cached_gdrive_id、get_cached_gdrive_file_bytes、狀態頁 _cached_status。入庫覆寫後與查詢頁「重新載入索引」會清 get_cached_gdrive_file_bytes 與 _load_history_inward_index_cached。

故障排除

現象先查
憑證缺失／無效Secrets 或 Actions Secret 是否有效
files.list 空service account 沒被加進該資料夾
找不到 mass_update / batch_edit檔名日期格式與 kind
統整表無法回寫雲端沒有既有主檔；API 不新建
歷史入庫只下載月份資料夾沒有同名檔
入庫索引未寫回ID_HISTORY_INWARD_INDEX 無效或沒有編輯權
查詢入庫看不到單檔未上傳或不在 YYYY/YYMM
UPC 填補 0 筆蝦皮列表空或 SKU 對不上 GTIN
重複匯入被拒md5 已在匯入紀錄
條碼對不上未經 clean_barcode；科學記號
畫面資料過期寫入後沒清 cache

監看用的蝦皮資料夾沒接流程是正常的。
