# 蝦皮商品清單轉換

路徑：商品蝦皮麗嬰統整管理 → 蝦皮商品清單轉換

## 本頁重點

- 從雲端抓最新 `mass_update_sales_info_3062950_YYYYMMDD*.xlsx`，校正 iSKU 後覆寫蝦皮主表。
- 同一檔 md5 已匯入會略過，避免重複覆蓋。
- 台北時間 10:00 後若今天還沒匯入，打開本頁會自動校正一次。

## 何時使用

蝦皮後台匯出最新「價格及庫存」mass_update 並放到對應 Drive 資料夾之後。

## 操作步驟

1. 確認頁面顯示將處理的最新來源檔與時間。
2. 按 **立即校正（抓取雲端最新 mass_update）**。
3. 成功後可預覽並下載校正結果。

備用：展開「手動上傳原始報表」，上傳本機檔再校正（同樣走 md5 去重）。

## iSKU 怎麼來

- 優先用「商品選項貨號」，否則用「主商品貨號」。
- 兩者都空則標「蝦皮無 iSKU」並排除。
- 同一 iSKU 留價格較後的一筆；有效 GTIN 再依 GTIN 去重。來源欄為 `國際條碼 (GTIN)`（舊檔仍可能是 `GTIN`）。

校正結果寫入 `蝦皮賣場商品列表.xlsm` 的「蝦皮商品列表」，並在「匯入檔案」記檔名、md5、匯入時間。

## 預期檔案

- 讀：`蝦皮_價格及庫存` 資料夾最新 mass_update
- 寫：`蝦皮賣場商品列表.xlsm`

其他蝦皮資料夾（媒體、標題描述、配送、未上架）只在狀態頁監看，本頁不會讀。

## 常見問題

- **找不到 mass_update_sales_info_3062950_…**：檔名或日期不對，或檔還沒上傳。
- **已校正過（md5 重複）**：同一份不會再覆寫；要重跑請換新匯出檔。
- **自動校正沒發生**：尚未到台北 10:00，或今天「匯入檔案」已有紀錄，或本頁這次連線已自動跑過。
