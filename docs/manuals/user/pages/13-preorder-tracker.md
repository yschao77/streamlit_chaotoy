# 預購追蹤

路徑：Sitegiant 電商整合管理 → 預購追蹤

側邊欄項目名稱是 **🗓️ 預購追蹤**。

畫面依任務分成五段，不要依「第 N 階」找按鈕。

## 本頁重點

- **1. 從廠商單帶入：** 勾選列寫入活動表（沒條碼只要勾選也會寫入）。對到既有列只更新廠商檔名／貨號／品名／條碼，不覆蓋 SKU、自購、上限、私密連結、結單日。**已實際關閉的列不覆寫。**
- **2. 補賣場資料並存檔：** 手填 SKU、自購、上限、月份、結單日後覆寫雲端 `預購追蹤.xlsx`。已填「實際關閉」的列不能改自購／上限／SKU／月份／結單日；品名、私密連結、條碼、貨號仍可改。清空實際關閉＝重開。
- **3. 對客戶訂單：** 只計 **商品名稱含「預購」** 的列，再依活動 SKU 計件，拆成 **已付款／未付款** 兩欄，並對上限。同時重寫 **預購訂單** 表、補上尚未列過的 SKU（預設「預購」）。雲端讀最新 `Orders_DD-MM-YYYY-*.zip` 並解成 xlsx。
- **4. 結單下載：** 勾選要結單的列，再預覽鎖定數量後確認。`訂量 = 自購 + min(客戶量, 上限)`。上限空＝不封頂；自購空＝0。未填 SKU、未勾選、已實際關閉的列不鎖定。下載已填訂量的廠商檔與 **SiteGiant 採購單**（後台：Purchase Order → Import Restock Products）。鎖定後在同一區覆寫雲端。
- **5. 到貨催款：** 只對已標 **到貨** 的 SKU：未付款產催款文；已付款且訂單狀態 **待處理** 產可打單名單。打單、取消、勾已收到付款仍在 SiteGiant。
- 寫回是覆寫既有檔，系統不會在 Drive 新建檔。
- SiteGiant 採購單官方空殼只給你本機下載（進階區），填好的檔也不會寫回那個空殼。
- 本機上傳的 Orders 只作看板預覽，不會上傳到 Drive。

狀態以 SiteGiant 官方為準：[訂單、付款與處理狀態的運作方式](https://support.sitegiant.com/zh/knowledge-base/how-the-order-payment-and-fulfillment-status-works-zh/#2-e8a882e596aee78b80e6858b)。工作表 **預購訂單** 不是官方訂單狀態「待處理」。

與先前工程分期對照：第1階＝第 2 段活動表；第2階＝第 3 段看板；第3階＝第 1 段匯入＋第 4 段結單；第4階＝第 5 段催款。

三張單分開看：

| 檔 | 用途 |
|----|------|
| 廠商訂購單 | 寄給廠商下單；結單只回填 `訂量` |
| SiteGiant 採購單 | 結單後上傳後台建 PO（填 iSKU＋鎖定數量） |
| 採購入庫單 | 貨到才用；現有「採購入庫單格式轉換」 |

## 何時使用

要從廠商訂購單帶入貨號／品名／條碼、登錄預購活動、查看已接單與付款兩欄、把 SKU 標到貨後催款／看未付款天數、結單後回填廠商訂量與下載 SiteGiant 採購單時。

## 操作步驟

左側選 **Sitegiant 電商整合管理** → **🗓️ 預購追蹤**。需要雲端最新內容時按 **重新載入預購追蹤**。計算規則與空殼下載在頁首摺疊區。

### 1. 從廠商單帶入

1. 上傳該次廠商原始訂購單（xlsx）。表頭不一定在第 1 列；系統會找訂量（或數量），以及條碼／貨號。品名、條碼、貨號欄名與麗嬰合併同一套同義（例如 `名稱`／`中文品名`／`品名規格`／`Description`，`條碼型號`／`JAN CODE`，`料品編號`／`Item No`）。
2. 預覽後勾選要跟的款。**沒條碼的列只要勾選也會匯入。**
3. 按 **把勾選列寫入活動表**。未勾選的列不寫入。
4. 同一檔再匯入一次時，已填的 SKU／自購不會被蓋掉。**已實際關閉的列整列不覆寫**（貨號／品名／條碼也不改）。

不要把整份廠商目錄無條件全選（麗嬰型可能上百列）。這一頁不從商品清單帶貨號（未來待做）。

### 2. 補賣場資料並存檔

1. 活動表左邊是月份、結單日、SKU、自購、上限；貨號／條碼在右邊。
2. SKU 填蝦皮 `自定義編碼`（與 SiteGiant 庫存 SKU 同一顆）。四款就填四個不同 SKU。不要把廠商貨號填進 SKU。
3. 空 SKU、同一 SKU 多列、SKU＝貨號，畫面會警告。
4. **已填實際關閉：** 自購、上限、SKU、月份、結單日不能改（畫面改了會還原）。品名、私密連結、條碼、貨號仍可改。要再改自購或重算訂量，先清空實際關閉（重開）。
5. 按 **覆寫雲端預購追蹤**。也可先下載本機副本核對。

活動表改 SKU 或上限後，下方看板會立刻依目前畫面重算，不必先存檔才能預覽。

### 3. 對客戶訂單

1. 看「雲端最新 All Orders」檔名與時間（資料夾 `Sitegiant_Preorder_Orders`，檔名 `Orders_DD-MM-YYYY-*.zip`，系統會解成 xlsx；例如 `Orders_16-09-2026-1789531035`）。
2. 若要核對本機匯出，打開 **本機上傳 All Orders 預覽**（預設收合，可傳 zip 或 xlsx）；畫面會標「未寫入 Drive」。
3. 看看板來源的檔案列數與 **預購列數**（商品名稱含「預購」）。
4. 摘要列顯示 **已接單／上限** 與已付款／未付款件數（都是 **商品數量** 加總）。點 SKU 列才看訂單明細。
5. **SKU 狀態**會自動補上預購列裡的 SKU，預設「預購」。標「到貨」後才進第 5 段催款。
6. **預購訂單明細**預設收合，含首次通知日與已過天數。
7. 已接單達到或超過上限會出現提醒。

### 4. 結單下載

1. 確認活動列已填 SKU。同一 SKU 不要出現在多列（畫面會警告）。
2. 在勾選表取消不要結的列（預設全勾；未填 SKU／已實際關閉的列不會出現）。
3. 按 **預覽鎖定數量**。鎖定數量 = 自購 + min(已接單, 上限)。核對表格後再按 **確認鎖定**。同場再確認會取代尚未存檔的廠商單歷史。已實際關閉、未勾選的列會列出「不鎖定」，不會進這次廠商單歷史。若改了勾選請再按預覽。
4. 下載已填 `訂量` 的廠商檔（只改訂量，標題與圖片會留著）。先對條碼，沒條碼再對貨號；對不上會列出來、不填假數量。
5. 下載 SiteGiant 採購單（iSKU + 鎖定數量）。拿到 SiteGiant Purchase Order → Import Restock Products 上傳。雲端空殼不會被改。
6. 在**同一區**按 **覆寫雲端預購追蹤**，把「廠商單歷史」、預購訂單、SKU 狀態、通知紀錄與實際關閉寫回 Drive。不必回到上方存檔。

### 5. 到貨催款

1. 先在第 3 段把該 SKU 標成 **到貨**。還沒標的不進催款／可打單。
2. **催款可複貼文**：到貨 SKU、付款狀態未付款、非已取消／已退款。可貼社群。
3. **可打單名單**：到貨 SKU、已付款、且訂單狀態＝**待處理**（官方才會出現在訂單處理頁）。已處理／已發貨／已完成不列入。
4. 按 **本次催款已通知**：幫催款文裡還沒日期的列點上今天；已有日期不改。日期寫在工作表 **通知紀錄** 與 **預購訂單**（不是活動表／SKU 狀態），並立刻覆寫雲端。第 5 段會列出通知紀錄；預購訂單明細有日期時會自動展開。不設取消門檻；要取消請到 SiteGiant。
5. 打單、勾已收到付款、Notify Customer 仍在 SiteGiant。

All Orders 若有顧客／收件／金額欄會一併帶上；沒有就不猜。

## 付款與訂單狀態怎麼用

| 用途 | 規則 |
|----|------|
| 已接單 | 商品名稱含「預購」、訂單狀態不是已取消；商品數量加總 |
| 已付款／未付款 | 只看 `付款狀態`。不看付款方式、不拆貨到付款 |
| 催款 | 到貨 SKU、未付款、非已取消、非已退款 |
| 可打單 | 到貨 SKU、已付款、訂單狀態＝待處理 |
| 已過天數 | 有首次通知日，且仍是未付款、未取消、未退款 |

官方常見路徑：銀行轉帳 → **新訂單 + 未付款**（催款）→ 你對帳後標記待處理並勾已收到付款 → **待處理 + 已付款**（可打單）。

對鍵用 All Orders **庫存SKU**；該格空白才改用 **商品SKU**。不過濾 `商城`。

## 活動表欄位

畫面由左到右：月份、結單日、SKU、自購、上限、品名、條碼、貨號、廠商檔名、私密連結、預計關閉、實際關閉。寫回雲端的欄位集合不變。有「實際關閉」的列鎖自購／上限／SKU／月份／結單日；清空該格＝重開。

SKU 填蝦皮 `自定義編碼`（與 SiteGiant 庫存 SKU 同一顆）。條碼填 GTIN／商品列表 `c`。貨號、廠商檔名通常由訂購單匯入。

`預購追蹤.xlsx` 另含工作表：預購訂單、SKU狀態、通知紀錄。

## 預期檔案

- 讀寫：`預購追蹤.xlsx`（既有 file id）
- 只讀：SiteGiant 採購單官方殼（填好的檔只本機下載，檔名如 `sitegiant採購單_預購_YYYYMMDD.xlsx`）
- 第 3 段讀取：`Sitegiant_Preorder_Orders` 的最新 `Orders_DD-MM-YYYY-*.zip`（解成 xlsx；也可本機上傳 zip／xlsx 預覽，不上傳）
- 第 1／4 段上傳：該次廠商原始訂購單（例如 `2026-License(SJ0910).xlsx`）

## 常見問題

- **無法載入預購追蹤**：service account 沒有該檔編輯權，或檔不是 `.xlsx`。
- **無法讀取 SiteGiant 採購單空殼**：service account 沒有該檔檢視權。看頁首摺疊「SiteGiant 採購單空殼」。
- **無法載入 All Orders**：資料夾是空的、沒有 `Orders_DD-MM-YYYY-*.zip`（或 xlsx），zip 內沒有試算表，或 service account 沒有該資料夾檢視權。可改本機上傳預覽。
- **看板件數是 0**：商品名稱沒有「預購」（現貨匯出）；或活動 SKU 與預購列的庫存SKU 不一致；或該 SKU 都是已取消。
- **催款文是空的**：SKU 還是「預購」、還沒標到貨；或沒有未付款列。
- **可打單是空的**：還沒改成官方「待處理」＋已付款。
- **廠商檔找不到表頭**：需要有訂量（或數量），以及條碼或貨號欄。品名／條碼／貨號可用麗嬰合併那套同義欄名（`名稱`、`中文品名`、`JAN CODE`、`Item No` 等）。xls 讀失敗請另存 xlsx。
- **已關閉列改不了自購／SKU**：這是保護；清空「實際關閉」即重開。廠商單再匯入也不會覆寫已關閉列。
- **訂量沒填上**：活動列沒 SKU（未鎖定），或條碼／貨號對不到。看畫面對不上清單。
- **SiteGiant 採購單匯入失敗**：iSKU 必須已在 SiteGiant 庫存。
- **匯入後 SKU 有值**：不是從廠商單帶入。新列 SKU 應空白；若條碼／貨號已在活動表，會保留該列原本的 SKU。貨號（如 `09398`）應在「貨號」欄。請重新整理頁面後再看欄位有沒有對齊。
- **廠商單歷史沒有自購**：請先在活動表填自購再預覽／確認鎖定；鎖定預覽列應看得到自購。然後在第 4 段覆寫雲端。
- **存檔後畫面仍是舊的**：再按重新載入；不要同時開兩個分頁互相覆蓋。
