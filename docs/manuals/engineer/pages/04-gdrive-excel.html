Google Drive 與 Excel

本頁重點

  • 來源目錄在 utils.TRACKED_SOURCES。
  • 禁止 API 新建檔；沒有 existing_file_id 就停止。例外：batch_edit_upc_added_only.xlsx 可用 allow_create=True。
  • 寫回 xlsm：keep_vba=True。條碼先 clean_barcode，儲存格 @。

連線

  • 選最新檔：pick_latest_gdrive_file（解析檔名日期）
  • Sitegiant 來源可含 zip：download_source_spreadsheet
  • 只讀可用 calamine；寫 xlsm 用 openpyxl + keep_vba=True
