# 麗嬰商品表合併和與審核

路徑：商品蝦皮麗嬰統整管理 → 麗嬰商品表合併和與審核

## 本頁重點

- 上傳麗嬰採購單 Excel，合併進 `麗嬰採購產品總表.xlsm`。
- 同一檔（md5）不會重複匯入。
- 條碼已存在但名稱或零售價不同，會標成衝突，需人工勾選處理。

## 何時使用

拿到新的麗嬰採購／報價 Excel，要寫入總表並處理重複條碼。

## 操作步驟

1. 選擇一個或多個 `.xlsx` / `.xls` / `.xlsm`。
2. 按 **開始一鍵合併到麗嬰總表**。
3. 看匯入報告：已匯入、重複檔案、無條碼欄位、異常衝突筆數。
4. 若有衝突，到下方「條碼重複與衝突即時審核控制台」：
   - 🔴 條碼重複且名稱不同
   - 🟢 條碼重複、名稱相同、零售價不同
5. 可改備註；勾選 `move` 的列會改存到「刪除紀錄」。
6. 按 **執行審核與資料儲存**。
7. 成功後可一鍵再跑三表整合並回寫統整表。

## 匯入規則（簡）

- 系統會找含「條碼／國際條碼／EAN」的表頭，並合併第 5、6 列這類複合表頭。
- 品名、條碼、零售價、貨號、內盒、CTN、含稅等欄會對應到總表欄名。
- 條碼已在總表且名稱、售價相同：不新增列。
- 條碼不存在：新增列，UID 往下流水。
- 條碼存在但名稱或售價不同：新增一筆衝突列並寫備註。

## 預期檔案

- 讀寫：`麗嬰採購產品總表.xlsm`
  - 工作表：`麗嬰國際產品總表`、`已處理採購單`、`刪除紀錄`、`metadata`
- 匯入歷史用檔案 md5 去重

## 常見問題

- **重複檔案**：同一份已匯過，會略過。
- **無條碼欄位**：表頭沒被辨識成條碼，或列都是空條碼。
- **未設定雲端主資料庫**：Drive 找不到麗嬰總表。
- 未要求前不要改稅率、八折、UID 後備值；那些是系統常數。
