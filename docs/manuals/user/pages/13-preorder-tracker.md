# 預購追蹤

路徑：Sitegiant 電商整合管理 → 預購追蹤

側邊欄項目名稱是 **🗓️ 預購追蹤**。

## 本頁重點

- 第1階維護雲端 `預購追蹤.xlsx` 的活動表。
- 可從廠商訂購單勾選列匯入（沒條碼只要勾選也會寫入）。對到既有列只更新廠商檔名／貨號／品名／條碼，不覆蓋 SKU、自購、上限、私密連結、結單日。
- 第2階用最新 All Orders：只計 **商品名稱含「預購」** 的列，再依活動 SKU 計件，拆成 Paid／貨到付款 Unpaid／銀行 Unpaid 三欄，並對上限。
- 第3階結單鎖定：`訂量 = 自購 + min(客戶量, 上限)`。上限空＝不封頂；自購空＝0。未填 SKU 不鎖定。可下載已填訂量的廠商檔與 Restock 匯入檔。
- 寫回活動表是覆寫既有檔，系統不會在 Drive 新建檔。
- Import Restock 官方空殼只給你本機下載，填好的 Restock 也不會寫回那個空殼。
- 本機上傳的 Orders 只作看板預覽，不會上傳到 Drive。
- 到貨催款文還沒做。

## 何時使用

要從廠商訂購單帶入貨號／品名／條碼、登錄預購活動（月份、結單日、SKU、自購、上限、私密連結）、查看已接單與三欄、或結單後回填廠商訂量與下載 Restock 時。

## 操作步驟

### 第1階：活動表

1. 左側選 **Sitegiant 電商整合管理** → **🗓️ 預購追蹤**。
2. 確認頁面能顯示 Restock 空殼檔名（代表只讀連線成功）。
3. 在活動表新增或修改列。SKU 填蝦皮 `自定義編碼`（與 SiteGiant 庫存 SKU 同一顆）。四款就填四個不同 SKU。
4. 按 **覆寫雲端預購追蹤**。也可先下載本機副本核對。
5. 需要雲端最新內容時按 **重新載入預購追蹤**。

活動表改 SKU 或上限後，下方看板會立刻依目前畫面重算，不必先存檔才能預覽。

### 從廠商訂購單匯入

1. 上傳該次廠商原始訂購單（xlsx）。表頭不一定在第 1 列；系統會找 `BARCODE`／`條碼` 與 `訂量`／`貨號`。
2. 預覽後勾選要跟的款。**沒條碼的列只要勾選也會匯入。**
3. 按 **把勾選列寫入活動表**。未勾選的列不寫入。
4. 再手填 SKU、自購、上限、月份、結單日，然後覆寫雲端。
5. 同一檔再匯入一次時，已填的 SKU／自購不會被蓋掉。

不要把整份廠商目錄無條件全選（麗嬰型可能上百列）。這一階不從商品清單帶貨號（未來待做）。

### 第2階：訂單三欄看板

1. 看「雲端最新 All Orders」檔名與時間（資料夾 `Sitegiant_Preorder_Orders`，檔名 `Orders_DD-MM-YYYY-*.xlsx`）。
2. 若要核對本機匯出，用 **本機上傳 All Orders 預覽**；畫面會標「未寫入 Drive」。
3. 看「看板來源」的檔案列數與 **預購列數**（商品名稱含「預購」）。
4. 每列活動顯示 **已接單／上限**，以及三欄件數（都是 **商品數量** 加總）。
5. 已接單達到或超過上限會出現提醒。
6. 展開該 SKU 可看訂單編號、商品名稱、SKU、件數、付款方式、付款狀態。

### 第3階：結單鎖定與兩檔

1. 確認活動列已填 SKU。同一 SKU 不要出現在多列（畫面會警告）。
2. 按 **結單鎖定**。鎖定數量 = 自購 + min(已接單, 上限)。
3. 下載已填 `訂量` 的廠商檔（只改訂量，標題與圖片會留著）。先對條碼，沒條碼再對貨號；對不上會列出來、不填假數量。
4. 下載 Restock 匯入檔（iSKU + 鎖定數量）。拿到 SiteGiant Purchase Order → Import Restock Products 上傳。雲端空殼不會被改。
5. 再按 **覆寫雲端預購追蹤**，把「廠商單歷史」與實際關閉寫回 Drive。

## 三欄怎麼拆

| 欄 | 規則 | 用途 |
|----|------|------|
| 已接單 | 商品名稱含「預購」、且未取消列的商品數量加總 | 對上限 |
| Paid | `付款狀態` = 已付款 | 可打單 |
| 貨到付款 Unpaid | `付款狀態` = 未付款，且付款方式含 `Cash on Delivery`／貨到付款／取貨付款 | 可打單、不催款 |
| 銀行 Unpaid | 其餘未付款 | 催款後才打單 |

對鍵用 All Orders **庫存SKU**；該格空白才改用 **商品SKU**。不過濾 `商城`。只計商品名稱含「預購」的列。`訂單狀態` = 已取消 的列不算。

## 活動表欄位

月份、結單日、SKU、條碼、貨號、品名、廠商檔名、自購、上限、私密連結、預計關閉、實際關閉。

SKU 填蝦皮 `自定義編碼`（與 SiteGiant 庫存 SKU 同一顆）。條碼填 GTIN／商品列表 `c`。貨號、廠商檔名通常由訂購單匯入。

## 預期檔案

- 讀寫：`預購追蹤.xlsx`（既有 file id）
- 只讀：SiteGiant Import Restock 官方殼（填好的檔只本機下載）
- 第2階讀取：`Sitegiant_Preorder_Orders` 的最新 `Orders_DD-MM-YYYY-*.xlsx`（也可本機上傳預覽，不上傳）
- 第3階上傳：該次廠商原始訂購單（例如 `2026-License(SJ0910).xlsx`）

## 常見問題

- **無法載入預購追蹤**：service account 沒有該檔編輯權，或檔不是 `.xlsx`。
- **無法讀取 Import Restock 空殼**：service account 沒有該檔檢視權。
- **無法載入 All Orders**：資料夾是空的、沒有 `Orders_DD-MM-YYYY-*.xlsx`，或 service account 沒有該資料夾檢視權。可改本機上傳預覽。
- **看板件數是 0**：商品名稱沒有「預購」（現貨匯出）；或活動 SKU 與預購列的庫存SKU 不一致；或該 SKU 都是已取消。
- **廠商檔找不到表頭**：需要有訂量（或數量），以及條碼或貨號欄。xls 讀失敗請另存 xlsx。
- **訂量沒填上**：活動列沒 SKU（未鎖定），或條碼／貨號對不到。看畫面對不上清單。
- **Restock 匯入失敗**：iSKU 必須已在 SiteGiant 庫存。
- **匯入後 SKU 有值**：不是從廠商單帶入。新列 SKU 應空白；若條碼／貨號已在活動表，會保留該列原本的 SKU。貨號（如 `09398`）應在「貨號」欄。請重新整理頁面後再看欄位有沒有對齊。
- **廠商單歷史沒有自購**：請先在活動表填自購再按結單鎖定；鎖定預覽列應看得到自購。然後再覆寫雲端。
- **存檔後畫面仍是舊的**：再按重新載入；不要同時開兩個分頁互相覆蓋。
