檔案職責

本頁重點

  • 新邏輯放 utils.py 或 views/，不要再把整份 app 複製進 temp/。
  • 共用函式只維護一份：頁面從 utils import。
  • save_to_master_xlsm / save_to_shopee_master_xlsm 以 utils 簽名為準。
路徑職責
app.pypage_config、側邊欄路由、組 gdrive_cfg
utils.pyDrive I/O、TRACKED_SOURCES、清洗、主表讀寫、同步
views/status_page.py各來源最新修改時間
views/sitegiant_page.py入庫、歷史、查詢入庫、UPC、待處理
views/integration_page.py三表、麗嬰審核、蝦皮、查詢
scripts/薄包裝，呼叫 utils 的 run_*_sync
temp/舊快照，只讀
重複定義 app.py 仍有舊的 save_to_master_xlsm、clean_barcode 等。頁面實際 import 的是 utils。改行為時改 utils.py。

UI 慣例

  • st.set_page_config(..., layout="wide") 只在 app.py
  • UI 繁中 + 既有 emoji 標籤
  • 主操作按鈕 use_container_width=True
  • 跨 rerun 資料放 st.session_state，key 保持穩定

不要改的數字（未要求時）

稅率 1.05、零售八折 0.8、UID 後備 3473。
