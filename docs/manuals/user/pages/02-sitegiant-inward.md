# Sitegiant 採購入庫單格式轉換

路徑：Sitegiant 電商整合管理 → Sitegiant 採購入庫單格式轉換

## 本頁重點

- 貼上「國際條碼 + 數量」，對統整表產出 Sitegiant 入庫單。
- 廠商選「麗嬰」才帶入成本、稅款、零售與批發含稅價。
- 「庫存貨品名稱」來自統整表 `sitegiant庫存SKU`。缺 SKU 或缺名稱會進待處理清單。

## 何時使用

要把採購明細轉成 Sitegiant 可匯入的入庫單，並寫入歷史入庫資料夾。

## 操作步驟

1. 填 **訂單／銷貨單號**（預設當天 `YYYYMMDD01`）。
2. 選 **採購廠商**：麗嬰、Buyee、日亞、其他（其他可自訂名稱）。
3. 選 **銷貨日期**（寫入欄位為 `yymmdd`）。
4. 從 Excel 複製「國際條碼」與「數量」兩欄，貼到文字框，按 **解析並產生預覽表格**。
5. 在預覽表檢查、增刪列。
6. 按 **執行貨品名稱和成本稅款導入並紀錄待處理商品**。
7. 預覽結果後下載，並確認已上傳雲端歷史入庫資料夾。

貼上範例：

```text
4711234567890	2
4711234567891	5
```

只有一欄時，數量會當成 1。

## 系統會填什麼

以條碼對統整表欄位 `c`：

| 入庫欄 | 來源 |
|--------|------|
| 庫存SKU | 統整表 `自定義編碼`；找不到則「須新增 iSKU」 |
| 庫存貨品名稱 | 統整表 `sitegiant庫存SKU`；空白則「未知商品名稱」 |
| 成本／稅款／麗嬰零售價／麗嬰批發含稅價 | 僅廠商為麗嬰時，來自統整表對應欄 |

缺 SKU 記「須建立自定義編碼」；有 SKU 但沒名稱記「須建立賣場商品」。這些列會寫入待處理清單；之後同一條碼對得上時會自動從待處理清掉。

## 預期檔案

- 讀：`商品蝦皮麗嬰價格統整表.xlsx`
- 寫：歷史入庫資料夾的入庫單 `.xlsx`
- 連動：採購單待處理清單

入庫前請先跑過三表整合，否則 `sitegiant庫存SKU` 可能是空的。

## 常見問題

- **須新增 iSKU／未知商品名稱**：內部商品列表或 Sitegiant BasicInfo 還沒對上；去待處理頁處理。
- **轉換失敗，請填入銷貨單號**：單號空白或明細表是空的。
- **找不到統整表**：先到「PowerQuery 執行三表整合」回寫雲端。
