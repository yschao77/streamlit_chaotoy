本機啟動與憑證

本頁重點

  • Python 3.11、requirements.txt、streamlit run app.py。
  • 本機 Secrets：st.secrets["textkey"]；不要印出、不要 commit。
  • CLI／Actions：環境變數 GOOGLE_SERVICE_ACCOUNT_JSON。

啟動

pip install -r requirements.txt
streamlit run app.py

Dev Container 會在 8501 跑 Streamlit。不要無故加套件。

憑證放哪裡

環境來源
Streamlit 本機.streamlit/secrets.toml 的 textkey
CLI / GitHub ActionsGOOGLE_SERVICE_ACCOUNT_JSON
備援GOOGLE_APPLICATION_CREDENTIALS 路徑
禁止 不要把 JSON 寫進 workflow、README 或手冊範例的真實內容；不要 print secrets；錯誤訊息用「憑證缺失／無效」。Drive 資料夾 ID 可以寫在程式；private_key 不行。

Drive 權限

新資料夾必須把 service account 的 client_email 加成檢視者，否則 files.list 會是空的。需要寫回的資料夾要編輯者。

本機不要提交的匯出檔

.gitignore 已排除 batch_edit_basic_info_all_*.xlsx、mass_update_sales_info_*.xlsx 等。不要 git add -f。
